## Comparativos: comparar dos cosas

Se usan para decir que algo es **más… que** otra cosa. Después se pone **than** (que).

| Tipo de adjetivo | Regla | Ejemplo |
|---|---|---|
| **Cortos** (1 sílaba) | + **-er** | *tall → taller*, *small → smaller* |
| Acaban en **-e** | + **-r** | *nice → nicer*, *large → larger* |
| Vocal + consonante | **doblan** la consonante + **-er** | *big → bigger*, *hot → hotter*, *thin → thinner* |
| Acaban en **-y** | **-y** → **-ier** | *happy → happier*, *funny → funnier*, *easy → easier* |
| **Largos** (2 o más sílabas) | **more** + adjetivo | *beautiful → more beautiful*, *expensive → more expensive* |

- *An elephant is **bigger than** a mouse.*
- *Maths is **more difficult than** Art.*

## Superlativos: el más… de todos

Se usan para decir que algo es **el más… de un grupo**. Llevan **the** delante.

| Tipo de adjetivo | Regla | Ejemplo |
|---|---|---|
| **Cortos** | **the** + **-est** | *tall → the tallest* |
| Acaban en **-e** | **the** + **-st** | *nice → the nicest* |
| Vocal + consonante | **doblan** + **-est** | *big → the biggest* |
| Acaban en **-y** | **-iest** | *happy → the happiest* |
| **Largos** | **the most** + adjetivo | *the most beautiful* |

- *The cheetah is **the fastest** animal in the world.*
- *This is **the most interesting** book in the library.*

## Irregulares

| Adjetivo | Comparativo | Superlativo |
|---|---|---|
| **good** (bueno) | **better** | **the best** |
| **bad** (malo) | **worse** | **the worst** |
| **far** (lejos) | **farther / further** | **the farthest / furthest** |

> 💡 Para decir que dos cosas son **iguales**: **as + adjetivo + as** → *Tom is **as tall as** Ben.* (Tom es tan alto como Ben.)

## Vocabulario: adjetivos útiles

*tall / short* (alto / bajo) · *big / small* (grande / pequeño) · *fast / slow* (rápido / lento) · *old / young* (viejo / joven) · *heavy / light* (pesado / ligero) · *cheap / expensive* (barato / caro) · *easy / difficult* (fácil / difícil) · *strong / weak* (fuerte / débil).
