## ¿Qué es el sustantivo?

El **sustantivo** (o **nombre**) es la palabra que sirve para **nombrar** personas, animales, cosas, lugares, ideas o sentimientos: *niña, gato, mesa, Madrid, alegría*.

## Clases de sustantivos

| Clase | ¿Qué nombran? | Ejemplos |
|---|---|---|
| **Comunes** | Cualquier ser u objeto de una clase. Se escriben con **minúscula**. | *río, perro, ciudad* |
| **Propios** | Un ser u objeto **concreto** para distinguirlo. Se escriben con **mayúscula**. | *Tajo, Toby, Sevilla* |
| **Concretos** | Lo que se puede **percibir con los sentidos**. | *flor, música, coche* |
| **Abstractos** | Ideas o sentimientos que **no se perciben** con los sentidos. | *amistad, miedo, belleza* |
| **Individuales** | **Un solo** ser u objeto en singular. | *árbol, oveja, soldado* |
| **Colectivos** | Un **conjunto** de seres en singular. | *bosque, rebaño, ejército* |
| **Contables** | Lo que se puede **contar**. | *libro, manzana* |
| **Incontables** | Lo que **no** se puede contar por unidades. | *agua, arena, harina* |

> 💡 **Truco para los abstractos:** si no lo puedes ver, oír, tocar, oler ni saborear, es abstracto.

## El género

- **Masculino:** van con *el, un*: *el niño, el sol*.
- **Femenino:** van con *la, una*: *la niña, la luna*.

**Formación del femenino:**

- Cambiando **-o** por **-a**: *gato → gata*.
- Añadiendo **-a**: *profesor → profesora*.
- Con terminaciones especiales: *actor → actriz*, *príncipe → princesa*, *gallo → gallina*.
- Con **palabras distintas** (heterónimos): *hombre → mujer*, *caballo → yegua*, *toro → vaca*, *padre → madre*.
- Algunos tienen **una sola forma** y el género lo marca el artículo: *el/la cantante*, *el/la estudiante*.

## El número

- **Singular:** uno solo → *lápiz*.
- **Plural:** varios → *lápices*.

**Formación del plural:**

- Terminados en **vocal átona** o **-á, -é, -ó**: se añade **-s** → *casa → casas*, *sofá → sofás*.
- Terminados en **consonante**: se añade **-es** → *árbol → árboles*, *canción → canciones*.
- Terminados en **-z**: cambian la **z** por **c** y añaden **-es** → *lápiz → lápices*, *pez → peces*.
- Algunos **no cambian**: *el lunes → los lunes*, *la crisis → las crisis*.
